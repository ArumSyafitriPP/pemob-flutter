## 🎨 Tahapan Perancangan

**1. Wireframe**

Wireframe merupakan rancangan awal aplikasi yang menggambarkan susunan halaman, menu, tombol, serta alur navigasi menggunakan tampilan sederhana berwarna hitam, putih, dan abu-abu.

**2. Mockup**

Mockup merupakan pengembangan wireframe menjadi desain visual yang lebih detail dengan penggunaan warna putih, hijau sage, dan krem. Desain dibuat dengan konsep *clean*, minimalis, dan ramah bagi orang tua atau wali murid.

**3. Prototype**

Prototype merupakan simulasi interaktif dari desain aplikasi yang memungkinkan pengguna mencoba perpindahan halaman dan navigasi melalui tombol yang telah dihubungkan menggunakan fitur Prototype pada Figma.

## 📋 Fitur dan Halaman Aplikasi

Prototype SPMB SD mencakup beberapa bagian utama:

### 1. Autentikasi Pengguna
- Halaman Awal
- Masuk (Login)
- Daftar Akun
- Lupa Password

### 2. Pendaftaran Murid Baru
- Dashboard Orang Tua/Wali
- Pengisian Data Calon Murid
- Unggah Dokumen Persyaratan
- Pemilihan Jalur Pendaftaran
- Pemilihan Sekolah Tujuan
- Konfirmasi Data Pendaftaran

### 3. Informasi dan Hasil Pendaftaran
- Status Pendaftaran
- Detail Pendaftaran
- Hasil Seleksi
- Informasi Daftar Ulang

### 4. Profil dan Pengaturan Akun
- Profil Orang Tua/Wali
- Ubah Profil
- Ubah Password

## 🧭 Panduan Penggunaan Prototype

Untuk mencoba prototype aplikasi SPMB SD, ikuti langkah-langkah berikut:

1. **Buka Prototype:** Akses tautan Figma yang tersedia menggunakan browser.
2. **Halaman Awal:** Pilih tombol Masuk atau Buat Akun Baru untuk memulai simulasi.
3. **Autentikasi:** Ikuti alur Login atau Registrasi untuk menuju Dashboard Orang Tua/Wali.
4. **Pendaftaran Murid:** Pilih Mulai Pendaftaran, kemudian ikuti tahapan pengisian data calon murid, unggah dokumen, pemilihan jalur, dan sekolah tujuan.
5. **Konfirmasi Pendaftaran:** Periksa informasi pendaftaran sebelum melanjutkan simulasi pengiriman.
6. **Status dan Hasil Seleksi:** Jelajahi halaman status pendaftaran, detail pendaftaran, hasil seleksi, dan informasi daftar ulang.
7. **Profil Pengguna:** Buka menu Profil untuk melihat informasi akun serta halaman Ubah Profil dan Ubah Password.

**Petunjuk Interaksi:** Jika ingin mengetahui tombol yang dapat diklik, klik area kosong pada tampilan prototype untuk menampilkan *hotspot highlight* pada elemen interaktif, apabila fitur tersebut tersedia.
